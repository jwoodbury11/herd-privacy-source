# Event invitation link previews

These 1200x630 PNGs are deterministic composites of the approved transparent
event scenes on Herd's `#1C1C1E` canvas. Invitation metadata selects the
matching image while the event title and `Reply privately. Plan honestly.` are
rendered by Messages or another link-preview client.

Keep the filenames aligned with the canonical event image IDs. Do not add event
or attendee data to these static files.
